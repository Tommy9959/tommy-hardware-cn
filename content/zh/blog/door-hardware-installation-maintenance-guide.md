# 尼日利亚门控五金安装维护指南：10年经验分享

*我是Tommy。做了十年门控五金出口——拉各斯、阿布贾、哈科特港、Onitsha、卡诺，都发过。见过漂亮的门被糟糕的安装毁了，也见过便宜的五金件对位了就能用好几年。*

## 一、门锁安装——最常见的错误（以及怎么修）

我每周都会接到电话："Tommy，锁对不上位。锁舌卡不进去。钥匙转了但没反应。"十次里有九次，不是锁的问题——是安装的问题。

**在尼日利亚我看到最多的三个问题：**

### 锁体跟锁扣板对不准

这是头号问题。门下沉了、门框变形了、或者孔位打偏了一点点。新装的好锁一下子就锁不上了。

**怎么修：** 别急着怪锁。先把门关上，看看锁舌实际打在锁扣板的哪个位置。如果偏差在1-2 mm以内，用锉刀把锁扣板的孔扩大一点就行。偏差超过2 mm的话，可能要凿掉重装锁扣板。一把圆锉刀加一双稳手，能解决80%的"锁坏了"投诉。

### 背距量错了

背距就是从门边到钥匙孔中心的距离。尼日利亚常见的是60 mm（2-3/8英寸）或70 mm（2-3/4英寸）。但我见过本地做的门用50 mm的——甚至还有完全随意的尺寸。

**怎么修：** 下单之前一定要量好。如果你是进口商转给下游零售商，一定要让他们确认门的厚度和背距。用那种可以调60 mm到70 mm通用锁舌，能省很多麻烦。

### 螺丝太差

这个问题让我特别抓狂。有些低价锁配的螺丝是软金属做的，拧第一圈就滑丝了。在尼日利亚潮湿的气候下，还特别容易生锈。

**怎么修：** 把原装螺丝直接扔掉。换不锈钢螺丝，至少3/4英寸长。握力更好、不锈。每把锁多花大概50奈拉，省后面几个月的麻烦。

**我的安装铁律：** 如果螺丝拿在手里感觉很软，它一定会出问题。安装第一天就换掉它。

## 二、合页维护——对抗尼日利亚的潮气和锈蚀

尼日利亚对合页特别不友好。我见过看起来好好的SS304不锈钢合页在拉各斯出问题——就因为有人混用了几个碳钢螺丝，锈水顺着合页线往下淌。也见过用了六个月就开始下坠的合页——因为螺丝太短，松了。

**在尼日利亚，合页要这样维护：**

### 选对材质

这点没得商量。沿海城市——拉各斯、哈科特港、卡拉巴尔——**必须用SS304不锈钢合页**，没有其他选择。空气中的盐分一年之内就能把镀锌或低碳钢合页吃穿。阿布贾和北部地区用好的镀锌钢也行，但SS304长期看还是更划算。

我见过施工队为了省每个合页500奈拉买了低碳钢，结果18个月后花5000奈拉全部换一遍。别干这种事。

### 定期润滑

WD-40不是答案。它能排水但挥发太快。在尼日利亚的湿度环境下，更好的选择是：
- **锂基润滑脂**（重型门最好用）
- **矽质润滑剂**（家用，不吸灰）
- **3合1润滑油**（经典款，够用）

**润滑频率：** 沿海地区每3个月做一次。干燥地区每6个月做一次。记在日历上——真的管用。

### 注意螺丝

门每天开关，合页螺丝会慢慢松掉。在尼日利亚的高温下，螺丝周围的木头会干缩，螺丝就更松了。

**怎么修：** 感觉门开始下沉的时候，几乎都是合页螺丝的问题。换成更长的螺丝（2英寸最好），让它咬进门框深处。或者用木头火柴棍蘸白胶塞进螺丝孔里再拧回去。老办法，但特别好用。

### "锈蚀蔓延"问题

有时候合页本体没事，但锈从合页销或螺丝头上蔓延过来。我见过几百扇门毁在这个问题上。

**预防方法：** 在装合页之前，给合页销涂一层薄薄的汽车润滑脂或凡士林。室外的门，考虑用不锈钢的合页销——就算合页本体是镀锌的也没关系。通常来说不同金属混用不好，但镀锌合页配不锈钢销，寿命比镀锌销长得多。

## 三、门把手松动——别硬掰，好好修

门把手晃晃悠悠是最烦人的问题之一，而且会越来越严重。在尼日利亚，常见的原因有这几个：

### 紧定螺丝松了

现在的门把手大多靠把手底部或侧面的小螺丝固定。每天拧来拧去，慢慢就松了。

**怎么修：** 用内六角扳手拧紧。滴一滴蓝色的Loctite螺纹锁固胶，防止它再次松动。**不要用万能胶**——粘上就再也没法拆了。

### 方杆磨损

连接内外把手的方杆在几千次转动之后会磨损。便宜的方杆钢材软，棱角会被磨圆。

**怎么修：** 换硬质钢方杆。贵一点但寿命长5倍。如果把手本身的方孔也磨损了，那就整套换——孔都圆了，再怎么拧也没用。

### 门的安装孔开太大了

钻孔的时候开大了，把手在孔里晃。

**怎么修：** 用玫瑰盖板（装饰面板）遮住缝隙。不够的话，在孔里加一个薄塑料或橡胶垫圈。有些客户用胶带在把手主体上缠一圈应急——不优雅，但临时管用。

### 门缝太小

门和门框之间的缝隙太小，每次开门把手都会蹭到门框。尼日利亚很多水泥门框会随着时间沉降，这个问题特别常见。

**怎么修：** 最少需要3 mm的间隙。如果不够，磨锁扣板那一侧的门边，不要磨合页那一侧。磨合页侧会影响整扇门的对位，越搞越麻烦。

## 施工队工具箱——每个尼日利亚承包商应该带什么

这些年我总结了一套工具清单，能搞定95%的门控五金安装活。大部分在Alaba市场都能买到：

| 工具 | 为什么要带 |
|------|----------|
| **圆锉刀** | 扩不对位的锁扣板孔 |
| **内六角扳手套装（公制）** | 拧紧把手紧定螺丝 |
| **充电钻配高速钢钻头** | 打螺丝导向孔（防木头开裂） |
| **2英寸不锈钢螺丝（混装）** | 替换原装软螺丝 |
| **锂基润滑脂/矽质润滑剂** | 润滑合页 |
| **蓝色Loctite螺纹锁固胶** | 防止把手螺丝震松 |
| **凿子套装** | 开锁扣板和合页槽 |
| **水平尺** | 装五金前检查门是否正 |
| **铅笔和尺子** | 标记位置——永远不要"目测" |
| **WD-40/渗透润滑剂** | 松锈死的螺丝和卡住的锁舌 |

**内行小贴士：** 工具箱里常备一盒火柴。把火柴棍塞进滑丝的螺丝孔再加木工胶，这是最快的老式修复方法。

### 加餐：五金到货就生锈了怎么办（还没安装呢）

这种情况比你想象的更常见。一个柜的货在Apapa港搁几周，潮气一上来，到经销商手里合页已经出现表面锈点了。

**别慌。** SS304不锈钢表面的锈是外观性的——镀上了运输过程中钢粉颗粒形成的氧化层。用醋和水的混合液（1:1）擦，立刻擦干。顽固的锈点顺着纹理方向用细砂海绵擦就行。下面那层不锈钢是好的。

**真正的腐蚀**——起皮或剥落——那就是另一回事了。如果金属真的在腐蚀，说明材质不对（很可能是SS201或普通钢冒充不锈钢），或者镍含量被偷了。那种五金件必须换。我们每批货出厂前都测过，但如果你从任何供应商收到的货出现超过表面浮锈的腐蚀，坚决要求退款。

## 尼日利亚的季节性维护清单

尼日利亚一年分旱季和雨季，对五金的影响各不相同：

**雨季来临前（3-4月）：**
- 所有室外门的合页重新打油
- 检查门缝密封条有没有缝隙（白蚁喜欢湿木头）
- 把室外门上所有看得见的螺丝拧一遍
- 测试所有锁——如果现在就觉得紧，到了湿度高峰只会更糟

**旱季来临前（10-11月）：**
- 润滑合页——旱季积灰会让合页变涩
- 用压缩空气吹锁芯（锁芯里的灰尘会导致卡顿）
- 检查木头缩水后有没有螺丝松动

**拉各斯/沿海地区全年坚持：**
- 每月用干布擦拭外露五金件
- **绝对不要用含漂白剂的清洁剂擦不锈钢**——会腐蚀保护层
- 看到小锈点立刻处理——沿海的锈蚀蔓延得很快
