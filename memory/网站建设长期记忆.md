## 💡 经验教训

### 成功经验
1. Hugo 构建速度快，适合外贸网站
2. GitHub Pages 零成本部署
3. 多语言支持完善
4. 移动端优先设计

### 踩过的坑
1. GitHub Pages 目录从 public/ 改为 docs/
2. Hugo 模板命名规则（list.html, single.html）
3. 阿拉伯语 RTL 布局需要特殊处理
4. GitHub 网络偶尔超时
