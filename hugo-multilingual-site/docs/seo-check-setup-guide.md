## 🔧 启用自动检查

### 方法一：使用系统 Cron（推荐）

1. **打开终端**

2. **编辑 crontab**
   ```bash
   crontab -e
   ```

3. **添加定时任务**
   复制以下内容并粘贴到 crontab：
   ```bash
   # SEO 每日检查 - 每天早上 9:00
   0 9 * * * cd /Users/zhuxiaolei/.openclaw/workspace/hugo-multilingual-site && ./scripts/gsc-daily-check.sh >> /Users/zhuxiaolei/.openclaw/workspace/logs/gsc-check-cron.log 2>&1
   ```

4. **保存并退出**
   - Vi/Vim: 按 `Esc`，输入 `:wq`，按 `Enter`
   - Nano: 按 `Ctrl+O`，`Enter`，`Ctrl+X`

5. **验证 crontab**
   ```bash
   crontab -l
   ```

## 🎯 关键指标说明

### 展示次数 (Impressions)
- **定义：** 网站在搜索结果中出现的次数
- **正常：** 稳步增长
- **异常：** 连续 7 天下降 → 需要检查

### 点击次数 (Clicks)
- **定义：** 用户点击网站链接的次数
- **正常：** 随展示次数增长
- **异常：** 展示增加但点击不增 → 优化标题/描述

### 点击率 (CTR)
- **定义：** 点击次数 ÷ 展示次数
- **正常：** 2-5%
- **异常：** < 1% → 优化标题和描述

### 平均排名 (Position)
- **定义：** 网站在搜索结果中的平均位置
- **正常：** 逐步提升
- **异常：** 突然下降 > 5 位 → 检查是否有问题

### 索引页面数
- **定义：** 被 Google 收录的页面数量
- **目标：** 接近网站总页面数（170+）
- **异常：** 远少于总页面数 → 检查 sitemap

## ⚠️ 常见问题处理

### 问题 1：索引错误突然增加
**可能原因：**
- 服务器问题
- 大量 404 页面
- sitemap 错误

**处理方法：**
1. 查看具体错误类型
2. 检查网站日志
3. 联系黛玉修复

### 问题 2：展示次数下降
**可能原因：**
- 季节性波动
- 竞争对手优化
- Google 算法更新

**处理方法：**
1. 检查是否是行业普遍现象
2. 分析竞争对手
3. 优化内容质量

### 问题 3：点击率低
**可能原因：**
- 标题不吸引人
- 描述不相关
- 排名太低

**处理方法：**
1. 优化页面标题
2. 优化 Meta 描述
3. 提升内容质量
