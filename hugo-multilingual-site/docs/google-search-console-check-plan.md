# Google Search Console 定期检查计划

## 📅 检查频率

### 每日检查（9:00 AM）
- [ ] 索引状态检查
- [ ] 错误提醒检查
- [ ] 新发现页面数

### 每周检查（周一 9:00 AM）
- [ ] 效果报告（展示次数、点击次数）
- [ ] 平均排名变化
- [ ] 索引覆盖率
- [ ] 核心网页指标

### 每月检查（每月 1 号 9:00 AM）
- [ ] 整月趋势分析
- [ ] 关键词排名变化
- [ ] 外部链接变化
- [ ] 移动端 usability 问题

---

## 📊 检查指标

### 1. 索引状态
- 已编入索引的页面数
- 有错误的页面数
- 被排除的页面数

### 2. 搜索表现
- 展示次数（impressions）
- 点击次数（clicks）
- 点击率（CTR）
- 平均排名（position）

### 3. 技术问题
- 抓取错误
- 移动设备问题
- 核心网页指标问题
- HTTPS 问题

### 4. 网站地图
- sitemap 状态
- 已发现页面数
- 最后读取时间

## ⏰ 定时任务配置

### 每日检查（9:00 AM）
```cron
0 9 * * * curl -s "https://search.google.com/search-console" > /dev/null 2>&1 && echo "GSC daily check completed" >> /tmp/gsc-check.log
```

### 每周检查（周一 9:00 AM）
```cron
0 9 * * 1 curl -s "https://search.google.com/search-console" > /dev/null 2>&1 && echo "GSC weekly check completed" >> /tmp/gsc-check.log
```

## 🎯 关键指标阈值

### 需要立即处理的情况
- ❌ 索引错误 > 10 个
- ❌ 移动设备错误 > 5 个
- ❌ 核心网页指标"差"的页面 > 20%
- ❌ sitemap 状态变为"错误"

### 需要关注的情况
- ⚠️ 展示次数连续 7 天下降
- ⚠️ 点击率 < 1%
- ⚠️ 平均排名下降 > 5 位
- ⚠️ 索引页面数减少
