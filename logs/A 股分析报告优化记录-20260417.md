## 🔧 主要改动

### 1️⃣ 数据源切换

**之前：** 依赖妙想 skill（mx-data）
- ❌ 需要安装外部 skill
- ❌ skill 被标记为可疑
- ❌ API 路径经常变化

**现在：** 直连东方财富 + 腾讯 API
- ✅ 无需 API Key
- ✅ 稳定可靠
- ✅ 数据实时

**API 端点：**
```javascript
// 大盘指数（腾讯）
http://qt.gtimg.cn/q=sh000001,sz399001,sz399006,sh000688

// 热点板块（东方财富）
http://push2.eastmoney.com/api/qt/clist/get?fs=m:90 t:2&fid=f3

// 股票榜单（东方财富）
http://push2.eastmoney.com/api/qt/clist/get?fid=f3  // 涨幅榜
http://push2.eastmoney.com/api/qt/clist/get?fid=f7  // 成交额榜
http://push2.eastmoney.com/api/qt/clist/get?fid=f23 // 量比榜
```

| **量能** | 0-20 分 | 量比>3 得 20 分，>2 得 15 分 |
| **资金** | 0-20 分 | 成交>50 亿得 20 分，>20 亿得 15 分 |
| **技术** | 0-15 分 | 换手>15% 得 15 分，>8% 得 12 分 |
