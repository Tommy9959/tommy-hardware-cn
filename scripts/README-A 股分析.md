**创建时间：** 2026-04-08  
**更新时间：** 2026-04-08 22:00

---

## 🎯 功能概述

专业的 A 股量化分析脚本，每天早上 9:40 自动推送分析报告。

**分析维度：**
- ✅ 基本面分析（主营业务、财务指标）
- ✅ 技术面分析（均线、MACD、支撑/压力位）
- ✅ 资金面分析（主力流向、北向资金、换手率）
- ✅ 估值分析（PE/PB/PS 分位）
- ✅ 风险提示（解禁、减持、业绩）
- ✅ 操作建议（关注位、止盈位、止损位）

---

## 📋 定时任务配置

**执行时间：** 每周一至周五 早上 9:40

**Crontab 配置：**
```bash
40 9 * * 1-5 /Library/Developer/CommandLineTools/usr/bin/python3 /Users/zhuxiaolei/.openclaw/workspace/scripts/stock-analyzer.py >> /Users/zhuxiaolei/.openclaw/workspace/logs/stock-analysis.log 2>&1
```

## ⚠️ 注意事项

1. **数据来源：** AkShare（免费财经数据接口）
2. **运行环境：** Python 3.9+
3. **依赖库：** `pip install akshare pandas numpy`
4. **执行时间：** 约 30-60 秒/只股票
5. **网络要求：** 需要访问东方财富、同花顺等网站

---

## 🔧 常见问题

### Q1: 脚本报错 "No module named 'akshare'"
**解决：** `pip3 install akshare`

### Q2: 数据获取失败
**原因：** 网络问题或 API 变更  
**解决：** 检查网络连接，或更新 akshare：`pip3 install --upgrade akshare`

### Q3: 定时任务不执行
**检查：**
```bash
# 查看 crontab 配置
crontab -l

# 查看 cron 服务状态
sudo launchctl list | grep cron
```
