## 🎯 功能概述

专业的 A 股大盘及热点板块分析脚本，每天早上 9:30 自动推送。

**分析维度：**
1. ✅ 大盘指数（沪指/创业板指/沪深 300）
2. ✅ 市场情绪（涨跌家数、涨停家数、连板高度）
3. ✅ 热点板块（涨幅前 10、跌幅前 10、主线判断）
4. ✅ 资金流向（北向资金、主力资金）
5. ✅ 明日展望（可能发酵方向）
6. ✅ 操作策略（激进/稳健/观望）

## 📊 分析框架说明

### 1. 大盘指数
- **上证指数** - 代表主板走势
- **创业板指** - 代表成长股走势
- **沪深 300** - 代表大盘蓝筹

**趋势判断：**
- 🟢 多头：收盘价 > MA20 > MA5
- 🔴 空头：收盘价 < MA20 < MA5
- 🟡 震荡：其他情况

### 2. 市场情绪
- **涨跌家数** - 市场整体赚钱效应
- **涨停家数** - 短线活跃度
- **连板高度** - 题材持续性

**赚钱效应评估：**
- 🟢 良好：涨停 > 50 家
- 🟡 一般：涨停 20-50 家
- 🔴 较差：涨停 < 20 家

### 3. 热点板块
- **涨幅前 10** - 当日最强板块
- **跌幅前 10** - 当日弱势板块
- **主线判断** - 持续性最强的板块

### 4. 操作策略
**偏多格局（2 个指数多头）：**
- 激进：6-8 成仓，积极参与
- 稳健：4-6 成仓，逢低布局

**偏空格局（2 个指数空头）：**
- 观望：0-3 成仓，等待信号

**震荡格局：**
- 高抛低吸：3-5 成仓
