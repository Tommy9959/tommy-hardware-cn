第二步：定价策略——正确定位

尼日利亚的 3 个定价层级

层级 定位 利润率 客户
经济型 最便宜选项 20-30% 价格敏感买家，小商店
中端 最佳价值 35-50% 大多数建筑商，中等商店（SOLA 最佳位置！）
高端 最佳质量 50-70% 高端项目，豪华住宅

SOLA 推荐定位：中端 = 最赚钱

为什么中端最有效：

  • 比经济型层级价格竞争少
  • 比经济型利润率好
  • 客户比"最便宜"更信任中端
  • 更容易建立忠诚度

定价示例（拉各斯零售）：

产品 SOLA 成本 您的价格 利润率
SOLA 插芯锁 $3.50 $7.00（₦5,600） 50%
SOLA 不锈钢把手 $2.50 $5.00（₦4,000） 50%
SOLA 轴承合页 $0.60 $1.20（₦960） 50%

要遵循的定价规则

1. 永远不要做最便宜的

  • 客户将"最便宜"与劣质联系起来
  • 您会得到价格敏感、不忠诚的客户
  • 没有质量问题或服务的空间

2. 不要只在价格上竞争

  • 竞争点：质量、可靠性、服务、信任
  • “相同价格，更好质量"是制胜信息

3. 提供数量折扣

  • 同款 10+ 件，95 折
  • 同款 50+ 件，90 折
  • 鼓励批量购买

4. 保持价格稳定

  • 不要每个月都变
  • 如果成本上涨，先向客户解释
  • 信任 = 稳定定价

第四步：客户忠诚度——让他们不断回来

80/20 法则：20% 的客户 = 80% 的收入

保持简单记录：

  • 电话/WhatsApp

  • 上次订单日期

简单系统：

  • 使用 Excel 或 Google Sheets
  • 或用笔记本（聊胜于无！）
  • 每笔订单后更新

如何使用：

  • “您好 Chukwu 先生——上次您买了 SOLA 插芯锁。还需要吗？”
  • “新到不锈钢把手——您上个月买了 200 个！”

忠诚度策略 2：为信任客户提供账期

何时提供账期：

  • 3-4 笔订单后（按时付款）
  • 对于定期客户（每月+）
  • 对于有 ongoing 项目的建筑商

SOLA 推荐的账期政策：

  • 老客户 30 天
  • 最高信用额度： 他们平均月订单的 50%
  • 要求： 期票或书面协议

忠诚度策略 3：售后服务 = 忠诚度

做这 3 件事：

1. 销售 1 周后跟进

  • “SOLA 锁用得怎么样？”
  • “安装有什么问题吗？”
  • 显示您关心

2. 快速处理投诉

  • 如果产品有缺陷，立即更换
  • 不要争论——把它做好
  • 一个处理好的问题会创造一个更忠诚的客户

3. 送小"感谢"礼物

  • 大订单送免费 SOLA 钥匙扣
  • 圣诞/新年送免费合页
  • 小举动 = 大忠诚度

忠诚度策略 4：产品知识 = 信任

了解您的产品：

  • SS201 和 SS304 有什么区别？
